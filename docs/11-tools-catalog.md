## Tool Data Structure

```typescript
interface Tool {
  id: string                // 'json-formatter'
  name: string             // 'JSON Formatter'
  category: string         // 'formatters'
  description: string      // 'Format and validate JSON...'
  icon: string             // '{ }'
  url: string              // '/tools/json-formatter'
  keywords: string[]       // ['json', 'format', 'validate']
  popular: boolean         // Is it in "Most Used Tools"?
  featured: boolean        // Show on homepage?
  isPremium: boolean       // Always false for now
}
```
