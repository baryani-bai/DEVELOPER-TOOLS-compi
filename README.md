## ✨ About

CodeBox is a comprehensive developer toolkit featuring 70+ free utilities designed with a sleek "Terminal Elite" aesthetic. All tools run client-side for maximum privacy and speed.

### 🎯 Key Features

- ⚡ **Lightning Fast** - Client-side processing, instant results
- 🔒 **Privacy First** - Your data never leaves your browser
- 🆓 **Forever Free** - All 70 tools, no premium tiers
- 🌙 **Dark Mode Native** - Terminal-inspired design, easy on the eyes
- 🎯 **Zero Bloat** - Just tools, no trackers or ads
- 🚀 **No Barriers** - No signup required

## 🎨 Design Philosophy

### Terminal Elite Aesthetic

- **Pure Black Backgrounds** (#000000)
- **Neon Green Accents** (#00ff41)
- **JetBrains Mono** typography
- **Sharp corners**, no rounded edges
- **Minimal shadows**, glow effects instead

### Core Values

- **Performance**: 95+ Lighthouse score
- **Accessibility**: WCAG AA compliant
- **Privacy**: No tracking, no data collection
- **Simplicity**: Just tools, nothing else

## 🛠 Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + CSS Variables
- **Fonts**: JetBrains Mono, Inter
- **Animations**: Framer Motion
- **Syntax Highlighting**: Prism.js / Shiki
- **Hosting**: Vercel (recommended)

## 🌟 Features Highlights

### Privacy by Design
All tools run 100% client-side. Your data never touches our servers.

### Keyboard Shortcuts
Power users can navigate with keyboard shortcuts:
- `Cmd/Ctrl + K` - Search tools
- `Cmd/Ctrl + Enter` - Execute tool
- `Escape` - Close modals
